- The Butler's replay gate no longer lets a candidate's change to who the Butler is reach the bundle's remote. It puts back any identity file the run changed (SOUL, IDENTITY, LORE or ASPIRATIONS) before sync resumes, and keeps the changed text in a root-only file beside the replay seeds. After such a change it runs no synced turn. If a file can't be put back, sync stays paused. The new `psyche-identity-untouched` result fails the gate and is never excused, and `no-sync-residue` now also fails if a Butler commit touches an identity file. On 0.1.0-alpha.1435, the gate's sync-timing turn pushed a candidate's SOUL.md edit to the remote.
