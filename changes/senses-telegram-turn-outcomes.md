- Every Telegram message the Butler takes in, from the owner or a household Friend, now ends with a recorded outcome: answered, silent or failed. If the Butler's process dies partway through a turn, Telegram sends the message again and the Butler runs it again, but only if nothing had gone out for it yet and it has used fewer than three tries. Otherwise it is recorded as failed, so the person never gets the same reply twice. Replies, reactions, files and approval cards all count as something that went out, and each is noted before it is sent. If that note cannot be written, nothing is sent, and the outbox does not send it later. A message whose turn was cut off before it was recorded runs again unless a reply had already been prepared for it. A message that runs again is logged as being replayed rather than as dropped. Before this, a message whose turn was cut off was dropped with only a warning in the log.
