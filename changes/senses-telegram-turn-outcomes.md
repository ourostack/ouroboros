- Every Telegram message the Butler takes in now ends with a recorded outcome: answered, silent or failed. If the Butler's process dies partway through a turn, Telegram sends the message again and the Butler runs it again, but only if nothing had gone out for it yet and it has used fewer than three tries. Otherwise it is recorded as failed, so the person never gets the same reply twice. Before this, a message whose turn was cut off was dropped with only a warning in the log.
