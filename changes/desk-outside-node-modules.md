- Desk's tools work again for agents on an installed Ouro. Since 0.1.0-alpha.1536, every agent's Desk server exited before it answered: Desk imports TypeScript files, and Node won't run TypeScript under `node_modules`. The daemon now runs the installed Desk from a copy in `~/.cache/ouroboros/desk/<tree>`, made once per Desk release. If the copy can't be made, Desk runs where it is, as before.
