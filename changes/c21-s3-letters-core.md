An agent can now file a letter for its person: something only they can answer, such as a decision between options, a task, an approval or a note. Six commands, each also an MCP tool and a tool the model is offered in every ordinary turn: `ouro mailbox send`, `list`, `read`, `wait`, `withdraw` and `deliver`. Letters are kept as one file each under the agent's `state/letters/`, written only by the daemon, which gives each a code such as L7. A second send with the same `dedupeKey` returns the letter already filed. Closed letters move to `state/letters/closed/` after 90 days and are never deleted. Nothing tells the person about a letter yet, and `deliver` always says the person has no answering handle; chat delivery and answers come in the next change. `ouro mailbox answer` and the `mailbox_answer` tool refuse every agent: only the person answers a letter. With the daemon down, every command says `daemon-down`.
