`ouro.ndjson` (the log every `ouro` command writes) is now size-capped like `daemon.ndjson`. Each `ouro` call is a short process that never wrote enough to trigger the size check, so the file grew without limit (284 MB on one host). The log now checks its size on its first write, so an oversized file rotates into the usual `ouro.N.ndjson.gz` generations the next time any `ouro` command runs.
