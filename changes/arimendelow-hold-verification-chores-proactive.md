Ouroboros no longer sends a proactive message that asks you to run a routine check ("open this and tell me if it shows") or that offers an untested result as the news. The message is held, and the agent that sent it is told to verify it itself and send the verified result with its proof, naming exactly what it checked. Sign-in, MFA, payment and other asks only you can answer, status updates you asked for that are labelled unverified, and replies in a conversation you started are unchanged.
