- An agent can now send a local image (png or jpg) with `surface` to a person on iMessage by naming it in `imagePath`; the text goes as its caption. Slugger's relay can deliver a screenshot to a phone instead of saying it can only send text (#1932). The image is checked before anything goes out, so an unreadable or non-image file sends nothing and says so. It needs family trust and refuses the sync-key directory, like `send_file`. Telegram, Teams, voice and held returns do not take an image yet and say so.
