The interviews command and grader take version 2 of the pre-registration as well as version 1. Each version is recognised by the SHA-256 its Appendix A gives for its allocation table, and any other table is still refused. A later version's sessions are marked started under their own ids, such as `v2/X-pilot`, so a session that already ran in version 1 can run once in version 2. Each report says which version it came from, and the grader refuses reports from a different version than the one it grades.
