The interviews command and grader take version 2 of the pre-registration as well as version 1. Each version is recognised by the SHA-256 its Appendix A gives for its allocation table, and any other table is still refused. Version 2 runs and is graded only in the reduced design, so both refuse it without `--reduced`. A later version's sessions are marked started under their own ids, such as `v2/X-pilot`, so a session that already ran in version 1 can run once in version 2. Each report and each request log line says which version it came from, and the grader refuses reports and log lines from a different version than the one it grades. The interviews command also takes `--copilot-account` and `--premium-multiplier`, which it passes to the Copilot target as the run command does. A run covers only its target model's sessions: by default those, and it refuses a named session for another model.
