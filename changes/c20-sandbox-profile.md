Eval sandbox: `runSandboxed` takes an optional agent profile, so a sandboxed run can put an agent other than the Butler in its container. The profile's bundle is mounted at `$HOME/AgentBundles/<agent>.ouro`, only its writable paths can be written, and the Telegram guest is started with `--agent <agent>`. A profile Docker could misread is refused before anything starts. Without a profile, a run is the Butler's and hands Docker exactly what it did before, byte for byte. The Docker job that runs the scripted sandbox cases in CI also runs a scripted interview conversation for an agent named `evalbot`, with no model call.
