A blind-interview arm can now carry its own replacement list, which pre-registration section 3 requires. The interview's guarded runtime rewrites every request with the arm's list before the brand-word scan: the system prompt, the tools, the messages, the tool results and the trace id. The model is sent only the rewritten request, and the scan still voids the session if a brand word gets through. A tool the list renames is handed back to the harness under its own name. A call's arguments are not mapped back, so an arm whose list rewrites paths must give those paths their neutral names in its sandbox. The scan reads the request as the guard sends it; a preamble a provider adds after that (the Anthropic setup-token provider's) is not scanned, and the interviews do not use that provider.
