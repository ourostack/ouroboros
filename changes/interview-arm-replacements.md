A blind-interview arm can now carry its own replacement list, which pre-registration section 3 requires. Every request the arm makes is rewritten by the list before the brand-word scan: the system prompt, the tools, the messages and the tool results. The model is sent only the rewritten request, and the scan still voids the session if a brand word gets through. A tool the list renames is handed back to the harness under its own name.
