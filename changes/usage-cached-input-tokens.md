Token usage now keeps the cached input tokens that a provider reports, as `cached_input_tokens`, from chat completions (`prompt_tokens_details.cached_tokens`) and from the Responses API (`input_tokens_details.cached_tokens`). It's left out when the provider doesn't report a number. Cached tokens are billed at a lower price, so an eval's report now has what it needs to price each call exactly. The eval's own budget still prices every input token at the full rate, which overstates cached calls.
