The interviews command takes `--host-lock <holder>`, as the eval's run command does. It holds the remote Docker host's lock for the whole command and sends its token with every job, so a Butler upgrade on that host waits for the interviews. The interviews wait up to 30 minutes for an upgrade in progress, then refuse. The lock lasts at most 6 hours. On the Butler's host, where the sandbox checks the lock, a job that finds it gone stops the study before it marks another session started, so only that one session is lost. The command refuses `--host-lock` without a holder, with a holder that isn't one safe word, or without `--sandbox-ssh`.
