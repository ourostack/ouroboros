- An agent's habits now run with its normal tools, the same as any of its other turns. The habit tool filter that denied every high-risk tool (shell, diary_write and others) is gone, and so is the habit file's `tools:` list. Only messaging outward is still bounded, by the habit's family, originator and extra recipients.
- Habits no longer have a paid-turn allowance of their own: a habit's cadence sets its pace. `habitPaidTurnsPerDay` in `agent.json` is no longer read, and an agent that still sets it is unaffected. External-event turns still count against the agent's shared proactive allowance and storm breaker.
- A habit with no origin no longer asks for an originator route, so its runs stop warning "originator route requested but habit has no origin".
- When a habit cannot run, for example because its definition is broken, the agent hears about it once in its private runtime instead of the habit failing quietly on every tick. It hears again only if the reason changes.
