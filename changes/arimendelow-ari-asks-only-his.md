- An ask on its way to a person (through `surface`, `send_message`, Teams or iMessage) now reaches them only when it names something only their body can do: approve a number or prompt on their own phone (2FA, GitHub Mobile, a passkey), pay with their card, or make an irreversible call that is theirs. An ask to run a command, press a key at a prompt, paste a code from their mail, sign in on a particular machine, accept terms or change a setting by hand goes back to the sender with "do it yourself; you have standing authority". A "you need to sign in to gh" ask is checked with `gh auth status` first and dropped when gh is already signed in. Sign-in, password and verification-code asks are no longer treated as theirs.
- The auth and mail docs no longer tell agents to hand browser logins, dashboards, API tokens, HEY export or DNS to the person: those are the agent's, with its vault and browser.
