- Desk is built into every agent. Ouro ships the Desk release that `desk.lock.json` pins and runs Desk's own MCP server, the same one Claude Code, Codex and Copilot run from the Desk plugin, on the agent's `desk/`. The agent changes its desk through Desk's tools (`mcp__desk__task_create`, `mcp__desk__task_update` and the rest), which commit and push each change under Desk's own commit messages, so the agent and coding agents work on the same desks the same way. Nothing needs installing.
- An agent can look after other desks, such as a team desk: list them in agent.json as `"desks": { "ari": "~/desk" }` and each gets its own Desk server, with tools named `mcp__desk-ari__*`. A desk that isn't on the machine is left out, and the prompt says so.
- The desk section of the prompt now tells the agent to change a desk only through Desk's tools, never by editing or committing its files, and lists the other desks it looks after.
- A plugin or agent.json server can no longer use the names `desk` or `desk-<name>`; one that does is left out with a warning.
