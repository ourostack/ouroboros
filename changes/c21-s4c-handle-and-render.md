- New `ouro mailbox handle set <person> <handle>`: the owner names the phone number (with its country code) or email address whose iMessages answer a person's letters. It is a CLI command only; no MCP or in-turn tool can set it. Each letter keeps the handle that was set when it was filed.
- Letters now have a plain-text chat form: code, sender and subject, the reason only you can answer, links by label, the "Options (from Ouro):" block, and the exact replies that answer it, such as `Reply "L7 1" or "L7 2".` A line anchor such as `#L12` is dropped from a link so it can't be mistaken for a letter code. Nothing sends it yet.
