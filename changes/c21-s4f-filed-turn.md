- Filing a letter now tells the agent that owns the mailbox. A note such as "letter L7 from desk/task: Which name? (decide, today)" goes to the agent's private runtime, and a wake has it read the note now, so the agent decides whether and when its person sees the letter. Each letter is told once: refiling the same letter by its dedupeKey, or a repeated wake, adds nothing. If the wake fails, the note waits for the agent's next private turn.
- The private-runtime policy allows this wake only when it names the letter and comes from the daemon's filing. A wake the policy denies is logged as a failure, with the note still queued. The note quotes the sender's lane and subject as the sender's own words.
