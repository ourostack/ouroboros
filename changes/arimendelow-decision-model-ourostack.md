An agent can now stay quiet in a group chat without paying for a model turn. Add `"replyGate": { "deployment": "<Microsoft-Decision deployment>" }` to agent.json and, before each group-chat turn, one call to Microsoft-Decision-1.1 on the azure provider's Foundry resource scores how valuable a reply would be; below `replyAtValue` (default 1.5) the turn ends as `observe` with no model call. It runs in iMessage groups, not Teams (where a bot hears only messages that @mention it), and never when a queued message is waiting for the turn. A message that names the agent, or any gate error or delay over 4 seconds, runs the turn as before. See "Reply gate in group chats" in docs/auth-and-providers.md.
