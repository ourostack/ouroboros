The Butler's host tools now read the Butler's name from the image they start (the name after `--package-managed-agent` in its entrypoint, else `sanctuary`). They use that name for every path inside the container: the bundle mount, the psyche mount, the trust mount `/etc/ouro/trust/<name>`, the vault and token containers, the bw profile, the replay gate, the sync cutover and the DockerMan template's bundle and trust Targets. The folders on the host never move: the bundle stays at `/mnt/user/appdata/ouro-butler/agent/sanctuary.ouro` and trust stays at `trust/sanctuary`. Resident mounts now use `--mount`, so a missing host folder stops the start instead of mounting an empty one. Preflight also refuses a leftover credential handoff that names another Butler, and a DockerMan template that can't be moved to the image's name. Every image still says `sanctuary`, so nothing changes until a release renames it.
