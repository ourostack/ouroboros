Pull requests no longer bump the version or edit changelog.json, so merging one no longer makes every other open pull request conflict. Each one adds a change note under changes/ instead, and the release job on main gives every landed change the next 0.1.0-alpha number, writes it into the package, the lockfiles, the wrapper and the Sanctuary deploy files, and adds the notes to the published changelog. A branch that still carries an old-style bump runs `npm run release:drop-bump`, then `git push --force-with-lease`: it moves the bump's changelog lines into a change note and rebuilds the branch as one commit on main.

A rebase merge of several commits now publishes one release with all of their notes, even when its last commit changes only docs or tests.

Releases publish to npm one at a time, in the order they landed, and a release that finds a later version already on npm's `latest` tag publishes on `alpha` instead of moving `latest` back.

The Unraid template's TemplateURL now points at the newest GitHub release's copy of the template, which carries the newest image's version.

Each release counts from npm's last release. Only a move to a new release line restarts the count, so a stale old-style bump that lands later is just another change and can't stop the releases after it. Every changelog entry since this change is rebuilt from the change notes on main on each release, so a release npm was slow to show, or one whose publish failed, never loses its notes, and the changelog never names a version npm doesn't have. Lockfile, SerpentGuide.ouro, RepairGuide.ouro and assets changes now publish too. The container image now waits for npm's release of the same commit and takes its version. A manual run of the container workflow now rebuilds only main's head, only when npm published main's version from that commit. `npm run butler:ship` finds a release's commit from npm, then from its release tag, since no commit subject names the version any more. A branch that changes the version in any commit, even one it later undoes, now fails the preflight.
