Agents no longer have messages held back for asking a person to do something. Version 0.1.0-alpha.1618 held any off-turn message asking for keyboard or machine work, and any "you need to sign in" message that `gh auth status` showed was false. This version removes both holds, along with the older hold on "please check this for me" requests. The rule now lives where agents read it, in the `send_message` and `surface` tool descriptions and the base prompt: ask a person only for what needs their body (a phone approval, their card, an irreversible call that's theirs, the vault's unlock secret), and do the rest under standing authority, checking a sign-in claim before passing it on. Untested delivery claims are still held and returned to the sender to verify.
