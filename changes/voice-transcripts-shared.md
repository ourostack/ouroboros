Voice notes from iMessage, Telegram and Teams are transcribed with whisper.cpp's large-v3-turbo model, using beam search and automatic language detection, in place of the small English-only model. A machine that already has the old model keeps using it while the new one (about 575 MB) downloads in the background. Every sense now labels a voice note "voice note (machine transcript; may mishear words)", and the agent is told that voice-note and call transcripts can mishear words: it reads for what the person most likely meant, and checks briefly when a misreading would change what it does.
