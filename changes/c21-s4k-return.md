- A letter filed from an agent's turn now remembers that turn's session. Once the person's answer is recorded, the daemon queues "Ari answered L7: 2 Ouro — after lunch" in that session, so the conversation that asked reads the answer on its next turn. A letter filed from the private runtime, the CLI or an MCP client has no session to return to. The agent's private runtime is told of every answer as before, and anyone waiting with `mailbox_wait` is released as before.
- Each try to return an answer writes a `returned` event. A try that fails is tried again after a minute, then after a doubling wait of at most an hour, until it succeeds.
- The session must be one the agent has really had turns in. A voice session gets no returned note, because a voice call drops notes older than a few minutes. The note comes from the mailbox, so Telegram's rule that drops an agent's own stale outreach doesn't remove it.
- The agent's private runtime note about an answer now names the session that asked, so the agent can raise the answer there sooner than that session's next turn.
- When another caller refiles a letter, the reply says the answer returns to the session that first filed it.
