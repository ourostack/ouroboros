- iMessage: the BlueBubbles webhook now listens only on 127.0.0.1, the address Ouro registers it at, and refuses a post without the server's password (before, a post with no password at all got through). Each refused post is logged as `senses.bluebubbles_webhook_unauthorized`.
- Turns asked for over the daemon socket (MCP `send_message`, `agent.ask`, `agent.senseTurn`) and over the frontend socket are now marked as socket turns. `friend_link_code` refuses them with code `socket-turn`, since a socket caller picks its own friend and channel and so can't prove the family member is there.
- The file and shell tools now refuse writes under `state/letters/`, the mailbox's letters. Paths are normalised before the check, so `state//letters/` and quoted paths are caught. The shell check now looks at every redirect and `tee` target in a command, `>>`, `>|`, `&>` and chained commands included, not just the first.
