The eval sandbox has a second interview guest, `h-guest-entry.js`, for the blind interviews' H product. H compares whole harnesses, so each arm runs its own agent loop rather than the neutral loop. The ouro arm is the harness's own Telegram turn on the mounted bundle, with the label line added to its system prompt and the debrief sent as the owner's next message. The other H arms plug in by name later. The sandbox's guest entries are now one list, which the agent image keeps; a test checks the Dockerfile against that list, and a scripted run of the ouro arm in the built image checks that everything the entry loads is there.
