`find_tools` now searches the agent's skills as well as its held-back tools. When a skill documents the job (for example a bundle command run through `shell`), the reply includes that skill's section, where its commands run from and how to open the whole skill, instead of only the closest tools or "no matching tools". One section per skill, at most two skills, clipped to about 900 characters. On Anthropic the section is sent next to the loaded tools' references instead of being dropped.
