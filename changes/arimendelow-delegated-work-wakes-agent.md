- When a coding session the agent started finishes, fails, is stopped, stalls or waits for input, the agent is woken right away with a message saying which session it was, who it was for, what it ended with, and to tell that person now with `send_message` instead of waiting for a check-back. This works whatever chat started the session (iMessage, Telegram, Teams, the CLI or the agent's own private turn), and for Orca, local and Workbench sessions alike. Before, only sessions started from the CLI tried to wake the agent, and the private-runtime policy refused even those.
- Orca and Workbench sessions are now checked every 30 seconds while any is still open, not only while someone is watching one, and a local session found dead after a restart is reported once.
- Copilot app session replies and finished coding work now reach the agent through one shared path: a message queued for the private runtime, then a wake.
