- When the person reads a letter in iMessage, the mailbox now records it as seen. The sense tells the daemon about the read receipt, and the daemon checks the BlueBubbles server's own copy of the message: Ouro sent it, into the chat the letter was delivered to, and the server has a read time. `mailbox_list` then shows `waiting, seen 2h ago`, and `mailbox_read` lists the `seen on chat` event, so an agent can tell its person has read the letter and doesn't ask again.
