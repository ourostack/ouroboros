New `ouro mailbox list` command, with the same action as the `mailbox_list` tool over MCP and inside a turn. It lists the letters an agent has filed for its person that still wait for an answer. Nothing can file a letter yet, so it always reports that none are waiting. All three doors are generated by ouro-actions from one declaration, `actions/mailbox.actions.mts`. The in-turn tool is registered but not yet offered to the model.
