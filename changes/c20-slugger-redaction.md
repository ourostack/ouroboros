Slugger's eval projection replaces each household name, handle or email it finds in a kept file with a fixed placeholder ("Member A", "member-a@example.invalid") instead of refusing the run, and reports only how many it replaced. Leak patterns now match whole words only (a name next to digits still matches), in the redaction and the leak lint alike; a file that isn't UTF-8 text is never rewritten, and is refused if it holds a pattern.
