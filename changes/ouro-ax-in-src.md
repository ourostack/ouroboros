The Ouro AX kit the harness vendors from Ouro UI now lives in `src/ouro-ax/` instead of `lib/ouro-ui/`, so the ouro CLI's own code can import it and compile it into the package. Ouro Current keeps updating it there each release. The kit's help module now builds into `dist/ouro-ax/`, and `ouro help --json` lists the kit's own programs (the X-ray, its flows runner and its surfaces checker) among the entry points, each with its card. Nothing else the CLI does changes yet.
