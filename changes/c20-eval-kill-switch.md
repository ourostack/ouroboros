Evals now have a stop button and money guards. While `~/.ouro-eval/STOP` exists, eval and interview batches refuse every new run and stop a running one at its next model call, and Watch exits before reading. `npm run eval:stop -- --sandbox-ssh <host>:<folder>` removes every eval container, network and image on that Docker host, frees an eval's host lock (never the Butler's) and checks that nothing is left. Each eval run is also refused when it could pass this month's cap of $40 in credits or 600 premium requests (`~/.ouro-eval/ledger-month.json`), or when its Copilot account reads under 20% of its quota left or gives no reading. Interview sessions add their spend to that month's total, so eval runs make way for the study, but the month cap never blocks or stops an interview, whose pre-registered caps still govern it. The host lock holder for `--host-lock` must now start with `eval`.
