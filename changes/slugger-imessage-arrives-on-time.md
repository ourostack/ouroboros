iMessage no longer misses a message that iMessage delivers minutes after it was sent. Catch-up used to look only at messages sent in the last 90 seconds, so a late message that BlueBubbles sent no webhook for waited until the next outage to be found (8.5 minutes on 2026-11-27). Each 30-second catch-up now also reads the rows that reached the Messages database since the last one, by arrival order, so the agent gets such a message within about 30 seconds of it landing, and the log says how late iMessage delivered it. If that turn fails or the catch-up runs out of pages, the next catch-up reaches back to the message again, for up to a day.
