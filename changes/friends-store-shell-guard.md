- The shell can no longer write an agent's friends store or product rules. The file tools already refused those writes for everyone. Now a shell command that names either folder runs only when every part of it plainly reads, so an A2A peer can't raise its own trust with `sed -i` ([#1949](https://github.com/ourostack/ouroboros/issues/1949)). The command counts as naming a folder when it does so through a path, a `cd`, the call's `cwd`, `~` or `$HOME`, a glob that could land there, or the home folder handed to `find`, `xargs`, `rm` and the like. The shell's `cwd` now counts for the psyche guard too, and `rm -rf ./psyche*` is refused again. Reads through `jq`, `sort`, and `find` without an action still work.
