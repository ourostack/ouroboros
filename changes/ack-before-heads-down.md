Nobody is left on read. When an agent can't answer a chat message in one quick reply, it now sends a short ack in its own words before going heads down, then keeps the person posted. On iMessage, Teams and Telegram, once the person has waited 15 seconds with nothing from the agent (5 seconds on a voice call), the engine holds the agent's next work call until it speaks, and it holds again if 5 minutes pass without an update (45 seconds on voice). The agent writes every word; the engine only holds the work and says why. Quick replies, group chats, reactions and habit turns are left alone.

iMessage agents can speak mid-turn again. The `speak` tool was hidden on iMessage while its sense could send only one reply per turn; the sense has recorded each mid-turn message durably since mid-November, so agents now get it there too. After a mid-turn iMessage lands, the typing dots come back while the agent keeps working.

Every agent's guidance says the same: tell the person first, in a line that shows you understood, keep them posted on real progress, then deliver. On mail, which sends one reply per turn, the agent replies with what it's doing and sends the result when it's done.
