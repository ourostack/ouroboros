New: `npm run eval:watch -- --agent-root <path>` reads a live agent's nerves logs and prints its turns as counts a day by channel: turns, how they ended, steps, step-budget stops, tool calls and errors, `find_tools` use, provider fallbacks and tokens. It reads only the lines added since its last run, follows log rotation, and stops after 30 seconds of CPU at the lowest priority. A scheduler should run the built file with `nice -n 19 node dist/eval/watch-entry.js`, since the npm script builds first. It keeps private rows under `~/.ouro-eval/watch/<agent>/` (owner-only), naming each turn only by a salted hash. It reads logs and nothing else: it never opens a session, sends nothing, starts no process, makes no model call, and refuses any write under `~/AgentBundles/` or the agent's folder. A summary line with a missing or malformed field is counted as rejected and never copied, and a field it doesn't know is left out. If it fails, it prints only an error code.

`engine.turn_summary` is now written at every log level, so turns on the iMessage, mail and voice senses (which log only warnings and errors) are counted too. It also names the runtime version.
