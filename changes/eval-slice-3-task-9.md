npm run eval runs the replay eval's cases on a real model (GitHub Copilot or MiniMax) against one bundle, in the sandbox locally or on another Docker host over ssh. Every run reserves its worst-case spend first, in premium requests and in credits, refuses to start without a Copilot multiplier or, for a pay-per-token target, without a credits cap, stops on the first 402 or 429, and writes a private report with pass@1 and Wilson intervals.
