- `ouro doctor` now says how far each agent's BlueBubbles address can be trusted with the server password, which every request carries. A server on the same Mac, behind https, or at a tailnet address passes. Plain http to anything else warns, as does an address that isn't an http or https URL; each says the mailbox won't read letter answers from it and names the fix. A MagicDNS name counts only over https.
- `ouro doctor` also says whether a shell beside the daemon could send iMessages as the agent's person. It compares the uid that owns the daemon's socket with the uid of the declared host account (`senses.bluebubbles.hostUsername`), the one signed in to the agent's own Apple ID, so it holds when `ouro doctor` runs as the person and the daemon doesn't. It passes when they match. A socket no daemon answers on counts as no daemon. Otherwise it warns that each letter answer is marked `shared-apple-id` until a human runs the daemon under that account.
