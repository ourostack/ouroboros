- When someone reacts to a message on iMessage, Telegram or Teams, the agent now reads what that message said ("loved your message: "are voice notes working?"") instead of a bare id. All three apps use one shared lookup: iMessage asks the BlueBubbles server for the message, Telegram reads the agent's own sent-message journal, and Teams reads a small new record of the agent's sent messages. When the message still can't be found, the agent is told so plainly and can ask.
