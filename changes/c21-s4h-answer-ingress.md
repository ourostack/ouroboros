- A person can now answer a letter by texting its code and an option number, such as `L7 2`, in the iMessage chat the letter went to. When a one-to-one message in answer form arrives, the BlueBubbles sense hands the daemon only its GUID, and the daemon decides from the server's own copy. A recorded answer is not a chat turn. Anything else, or a daemon that can't be asked, stays an ordinary chat turn.
- Once an answer is recorded, the person gets a one-line receipt in the same chat, such as `Recorded L7 Which name? → 2 Ouro`, so a misread answer shows at once. The agent is told in its private runtime and woken; the private-runtime policy allows that wake only for an answer the daemon recorded. A receipt or wake that fails is logged and never undoes the answer.
