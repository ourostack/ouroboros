An agent's messages no longer run sentences together, as in "...as promised.Quarantine retry is the big one". When the agent wrote a line, used a tool and then answered, the line and the answer reached the person as one message with no space between them. On iMessage, Telegram and mail, which send whole messages, the answer now goes out alone, and the agent's mid-turn messages still go out through `speak`. On Teams and the terminal, which show text as it is written, each message in a turn starts a new paragraph: the agent's line, each `speak` and the answer. The fix is in the shared engine, so every sense gets it.
