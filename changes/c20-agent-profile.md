Eval sandbox: an agent profile names the agent a sandboxed run puts in its container, where that agent's bundle comes from and which bundle paths the turn may write. The Butler's profile is today's bundle projection and today's writable paths, and is still the default; the sandbox itself moves onto profiles in a later change. The sandbox's guests no longer pick the Butler's bundle themselves. The Telegram guest takes the bundle its `--agent` names, though the Telegram turn still runs only the Butler. The interview guest runs on whichever one bundle the sandbox mounted. A new test pins every Docker command and every file a default run hands the agent container, for the replay eval and the interviews, byte for byte against recordings taken before this change.
