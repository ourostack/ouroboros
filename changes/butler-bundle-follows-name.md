- The Butler's media tools and its house rules no longer assume the bundle is mounted at `sanctuary.ouro`: the media server finds its credentials and state next to itself, and the instruction for house notes names `psyche/TACIT.md` in the bundle. Nothing changes for an install that is still called sanctuary.
- When the daemon runs the Butler under one name and finds its saved external events under the other name, it moves that folder over at start and treats those events as the running Butler's. If both folders exist it leaves both and logs a warning. A rollback moves them back the same way.
- The bundle migration takes `--butler-name <butler|sanctuary>`. When the bundle's own files (agent.json, the replay client's provision.json, recent attachments, skills and HOUSE.md) name the other Butler's container path, it points them at this one. The rollback record holds those files, so a rollback restores them exactly. Psyche, friends, sessions and logs are never touched.
