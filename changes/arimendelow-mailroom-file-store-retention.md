- Once an agent's mail is hosted (`mailroom.azureAccountUrl`), the daemon gzips the leftover local mail file store (`state/mailroom/messages` and `raw`), for messages older than 30 days. It never touches the file store while it holds the agent's mail, or when the daemon can't tell where the mail lives. It keeps `registry.json`, checks every gzip before removing the original, and logs counts only (`daemon.state_retention_mailroom`).
