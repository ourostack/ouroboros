- `mailbox_deliver` now sends a waiting letter to the person's iMessage chat, as the agent, through the agent's own BlueBubbles settings. The text is the one Ouro renders, never the agent's. It goes to the handle that was set when the letter was filed, and the letter records a `delivered` event saying where it landed. A dry run shows the exact text and sends nothing. It refuses with `not-waiting` for a closed letter, `chat-unavailable` when the daemon has no chat, and `send-failed` when the send fails, which leaves the letter waiting so it can be delivered again.
