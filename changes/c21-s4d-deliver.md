- `mailbox_deliver` now sends a waiting letter to the person's iMessage chat, as the agent, through the agent's own BlueBubbles settings. The text is the one Ouro renders, never the agent's. It goes to the handle that was set when the letter was filed, and the letter records a `delivered` event saying where it landed. A dry run shows the exact text and sends nothing.
- Each letter goes to the chat once. A second deliver is refused with `already-delivered`. A send that fails after it may have reached the chat, or that outlasts its 25-second deadline, counts as delivered (`send-uncertain`), so a retry never sends the person the same letter twice. A send that never reached the chat (`send-failed`) leaves the letter waiting. A letter whose expiry has passed isn't delivered. When the person has never messaged the agent from that handle, the refusal says so.
