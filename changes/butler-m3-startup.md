The Butler's container now prepares its packaged bundle at startup through its product registration, instead of the daemon calling Butler code directly. On the Butler's image it behaves as before. A daemon told to manage a packaged bundle (`--package-managed-agent`) that no product can prepare refuses to start, with the same roll-back guidance; that now includes an image whose `container-runtime.json` names no product. A daemon managing agents no product runs no longer checks Butler package management at all.
