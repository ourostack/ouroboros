`coding_spawn` on Orca now checks that the coding agent actually started in its terminal tab. It no longer trusts Orca's "handed to terminal" receipt, which only means the keystrokes were sent. If no agent shows up in the tab within 90 seconds, Ouro closes the tab and launches once more in the same worktree. If that also fails, the spawn fails and says what the terminal showed, for example `zsh: command not found: laude`.
